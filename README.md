    "# Netflix Data Analytics Project\n",

    "## Project Overview\n",
    "This project explores the Netflix titles dataset using Python and data analysis libraries.\n",
    "The goal is to understand the content available in the dataset through data cleaning,\n",

    "## Tools and Technologies\n",

    "- Matplotlib\n",
    "- Seaborn\n",
    "- Jupyter Notebook\n",

    "## Project Steps\n",
    "1. Loaded and explored the Netflix dataset.\n",
    "2. Checked and handled missing values.\n",
    "3. Analyzed Movies and TV Shows.\n",
    "4. Studied release-year and content-added trends.\n",
    "5. Analyzed countries, genres, ratings, and durations.\n",
    "6. Created visualizations to present the findings.\n",
    "\n",
    "## Key Findings\n",

    "- July had the highest number of titles added by month.\n",
    "- TV-MA was the most common rating for both Movies and TV Shows.\n",
